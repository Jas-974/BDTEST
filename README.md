# LocAchat

LocAchat est un site web permettant l’achat et la location de véhicules.

## Description
Ce projet est une application web simple qui permet aux utilisateurs de consulter des véhicules disponibles à l’achat ou à la location.

## Installation
Aucune installation particulière n’est nécessaire.

1. Cloner le dépôt ou télécharger le projet
2. Ouvrir le dossier du projet sur ton ordinateur

## Utilisation
Ouvre le fichier `index.html` dans ton navigateur pour lancer le site.

## Technologies utilisées
- HTML  
- CSS  
- JavaScript
- PHP
